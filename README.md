## 📌 Project Overview

This is a **full-stack Task Manager application** built using modern web technologies.
It allows users to **register, login, manage projects, and track tasks** with secure authentication.

---

## 🛠️ Tech Stack

### 🔹 Frontend

* React.js
* Axios
* Tailwind CSS
* React Router

### 🔹 Backend

* Spring Boot
* Spring Security
* JWT Authentication
* Hibernate / JPA

### 🔹 Database

* Neon PostgreSQL (Cloud Database)

### 🔹 Deployment

* Backend: Railway
* Frontend: Vercel

---

## ✨ Features

* 🔐 User Registration & Login (JWT Authentication)
* 👤 Role-based Access (Admin / User)
* 📁 Project Management
* ✅ Task Management (Create, Update, Delete)
* 🔎 Task Status Tracking
* 🌐 Fully Deployed Application

## ⚙️ How to Run Locally

### 1️⃣ Clone Repositories

```bash
git clone https://github.com/your-username/task-manager-ui
git clone https://github.com/your-username/task-manager-api
```

---

### 2️⃣ Run Backend

```bash
cd task-manager-api
mvn spring-boot:run
```

---

### 3️⃣ Run Frontend

```bash
cd task-manager-ui
npm install
npm run dev
```

---

### 4️⃣ Open Application

```text
http://localhost:5173
```

## 🔐 Authentication Flow

1. User registers
2. Backend generates JWT token
3. Token stored in frontend (localStorage)
4. Token sent in Authorization header for protected APIs
